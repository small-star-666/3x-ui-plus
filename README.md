* **订阅端口 (Subscription Port):** `2096`
  > 💡 **核心功能**：专门用于分发你那套带自动分流、完美对齐缩进的 Clash 订阅规则。请确保此端口处于开放状态。

  > 🛠️ **温馨提示**：此端口作为节点入站测试使用。后续在管理后台中创建新的 Vless / Vmess / Trojan 节点时，你依然可以**自由配置和更改**入站端口。
